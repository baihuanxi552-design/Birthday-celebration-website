# 510 · 年度寿星黑历史数字博物馆 Pro Max

生日限定互动网站：20件照片/视频馆藏、六间黑历史展厅、一位名叫「510」的寿星。

**在线访问：** https://baihuanxi552-design.github.io/Birthday-celebration-website/

## 怎么玩

- 先等待礼物盒下方进度条加载全部素材，点「拆开礼物」后进入摘头套仪式。首次全量媒体约120.5 MiB，建议Wi-Fi；加载失败可重试。
- 点击开屏揭面按钮，等待510摘下头套，礼花过后进入博物馆。未点击前只循环播放戴头套片段。
- 在首页给510戴皇冠、墨镜，或翻转成五兄弟西装形态。
- 在六间展厅解封睡颜、拖动断电滑块、八倍锁脸、触发警灯震屏和RGB故障，围观大师的语录弹幕。
- 在影院观看实际合成的66秒生日短片，支持声音、进度条与全屏。
- 到页尾吹灭蜡烛，收下「510，生日快乐！」及兄弟们的祝福。

## 文件与本地预览

纯HTML、CSS和JavaScript，无需安装依赖或构建。

| 文件 | 用途 |
| --- | --- |
| index.html | 页面结构、庆生文案、全部素材展示 |
| styles.css | 波普撞色、Bento布局、3D翻转、RGB和响应式样式 |
| app.js | 开屏、展厅、播放器、原图弹窗和生日彩蛋 |
| logic.js | 素材映射、连续叠化与八倍镜坐标 |
| motion.js | 半调网点、印章回弹和逐字挤压动画 |
| assets/ | 20项原始素材、开屏循环/封面及已合成正片 |
| server.mjs | 本地静态服务，支持视频Range请求 |
| VERIFICATION.json | 交付时的浏览器及媒体验证记录 |

安装Node.js后，在仓库目录运行 node server.mjs . ，然后打开 http://localhost:5180 。页面使用JavaScript modules，请通过HTTP服务预览。
